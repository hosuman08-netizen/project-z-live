워크스페이스 Workspace

개발자×AI 작업을 한 워크스페이스에서 — 요청을 보내고, 산출물과 실행기록을 남깁니다. Run developer × AI work in one workspace — submit requests, keep deliverables and run logs.

흩어진 채팅·파일 대신, 요청 단위로 진행 상태를 확인하세요. Track progress by request instead of scattered chats and files.

요청 Request

03

산출물 Deliverable

결과물을 요청에 묶어 한곳에서 확인합니다. Keep outputs attached to the request in one place.

04

실행기록 Run log

무엇을 실행했는지 기록이 요청과 함께 남습니다. What ran stays linked to the request.
